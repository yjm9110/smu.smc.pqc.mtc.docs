PQC File Sharing System

This repository contains the Java service and browser-side JavaScript library for a post-quantum file sharing system built around Merkle Tree Certificates (MTC), ML-KEM, and ML-DSA.

The Java module issues user certificates, constructs signed MTC states, and generates membership proofs. The JavaScript module verifies the certificates and proofs in the browser and provides the client-side key encapsulation and encryption workflow.

Quick start

Run the self-contained Java SQLite example:

cd java/PQC-MTC
mvn clean package
java -cp target/pqc-mtc.jar com.smu.TestSQLite

Build the browser library:

cd js
npm install
npm run build

The JavaScript build produces js/dist/pqc-lib.js and js/dist/pqc.wasm. Serve the js/ directory through a local HTTP server and open demo/index.html to run the browser demo; the WebAssembly asset cannot be loaded directly through a file:// URL.

Documentation

Browse the documentation homepage for the Java and JavaScript guides and API references. The published pages live in the docs-site submodule, which is a separate repository. GitHub Pages must be enabled on that repository's main branch at its root.

To regenerate every page from this repository's README files and source code, initialize the submodule and run:

git submodule update --init
cd js && npm ci && cd ..
./scripts/generate-docs.sh

Generate the Java API documentation from java/PQC-MTC/:

./maven_javadoc.sh

Generate the JavaScript API documentation from js/:

npm run docs

The individual commands also write into docs-site/. Commit and push changes in that submodule to publish them; the main repository's GitHub Actions workflow can perform regeneration and publication automatically after its documentation repository write token is configured.

For module-specific details, continue with the Java guide or the JavaScript guide.
