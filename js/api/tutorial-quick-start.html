Quick Start Guide

This guide demonstrates how to execute a simulated end-to-end cryptographic workflow integrating ML-KEM, digital certificates, and AES encryption using the pqc_funcs library.

Vue/Vite Setup

Build this library first, then copy dist/pqc-lib.js and dist/pqc.wasm into the Vue application's src/lib/ directory. Configure the WASM asset URL once in src/main.js, before the application calls any cryptographic API:

import pqcWasmUrl from "./lib/pqc.wasm?url";
import pqc_funcs, { setPqcWasmUrl } from "./lib/pqc-lib.js";

setPqcWasmUrl(pqcWasmUrl);

// Mount Vue only after the library has been configured.
// createApp(App).mount("#app");

Vite's ?url import emits the WASM file as an application asset and supplies the correct development or production URL. setPqcWasmUrl must be called before kemKeyGen, ML-KEM, or ML-DSA triggers the first WASM load.

Alternatively, place pqc.wasm in the Vue application's public/ directory:

import pqc_funcs, { setPqcWasmUrl } from "./lib/pqc-lib.js";

setPqcWasmUrl(`${import.meta.env.BASE_URL}pqc.wasm`);

The BASE_URL form also works when the Vue application is deployed below a subpath. A wrong URL causes the first cryptographic call to reject with a WASM initialization error containing the HTTP failure status.

End-to-End Workflow Example

The end-to-end workflow contains separate administrator and client-side stages. The administrator first creates and restores its signing keys, then issues and verifies a user certificate. The client-side example that follows uses certificates, membership proofs, ML-KEM, and AES encryption.

Administrator Key and Certificate Setup

The exported adminCertificateWorkflow example demonstrates the complete administrator flow: generate ML-DSA keys, export and re-import their PEM values, generate a user ML-KEM key, issue and export the certificate, extract the certificate's ML-KEM public key, and verify the ML-DSA signature. Its full implementation in src/examples.js is:

import * as pqc_funcs from "./pqc_funcs.js";

export async function adminCertificateWorkflow({
    userId = "UID-42",
    certInd = 42,
    createTime = Date.now(),
    validTime = 24 * 60 * 60 * 1000
} = {}) {
    // Generate the administrator ML-DSA signing key pair once.
    const { publicKey: adminPublicKey, privateKey: adminPrivateKey } =
        await pqc_funcs.dsaKeyGen();

    // Export PEM values for persistent storage. Keep the private key secret.
    const adminPublicKeyPem = await pqc_funcs.exportDsaPKToPem(adminPublicKey);
    const adminPrivateKeyPem = await pqc_funcs.exportDsaSKToPem(adminPrivateKey);

    // Re-import the stored keys, as an administrator would in a later session.
    const restoredAdminPublicKey =
        pqc_funcs.importDsaPKFromPem(adminPublicKeyPem);
    const restoredAdminPrivateKey =
        pqc_funcs.importDsaSKFromPem(adminPrivateKeyPem);

    // Generate the user's ML-KEM key and export its public part for signing.
    const { publicKey: userKemPublicKey } = await pqc_funcs.kemKeyGen();
    const userKemPublicKeyPem =
        await pqc_funcs.exportKemPKToPem(userKemPublicKey);

    // Issue an ML-DSA-signed X.509 certificate that binds the user ID to
    // the user's ML-KEM public key.
    const issuedCertificate = await pqc_funcs.issueUserCert(
        userId,
        certInd,
        userKemPublicKeyPem,
        restoredAdminPrivateKey,
        createTime,
        validTime
    );
    const userCertificatePem = pqc_funcs.exportCertToPem(issuedCertificate);

    // Parse the exported certificate and exercise the client-facing APIs.
    const certificate = pqc_funcs.decodeCertFromPem(userCertificatePem);
    const extractedUserKemPublicKey =
        await pqc_funcs.extractUserKemPK(certificate);
    const certificateValid = await pqc_funcs.verifyUserCert(
        certificate,
        restoredAdminPublicKey
    );

    // Treat a failed self-check as an issuance failure.
    if (!certificateValid) {
        throw new Error("The JavaScript-issued user certificate failed verification");
    }

    // Return the persisted values and parsed results for the surrounding app.
    return {
        adminPublicKeyPem,
        adminPrivateKeyPem,
        userKemPublicKeyPem,
        userCertificatePem,
        certificate,
        extractedUserKemPublicKey,
        certificateValid
    };
}

Persist adminPublicKeyPem and adminPrivateKeyPem using the application's secure key storage. The private key is an administrator signing credential and must not be exposed to browser users.

Client Encryption and Proof Workflow

The following script covers:

  1. Generating client-side ML-KEM keys.
  2. Managing and verifying Admin and User certificates.
  3. Encrypting a payload using AES-GCM combined with ML-KEM encapsulation.
  4. Handling re-encryption and decapsulation flows.
// Import the WebAssembly-based ML-KEM cryptographic provider library
import pqc_funcs from './lib/pqc-lib.js';

const adminCertPem = "-----BEGIN ADMIN CERTIFICATE-----MIIVwDCCCL2gAwIBAgIQXdcKqB9Yw+h...-----END ADMIN CERTIFICATE-----\n";
const userCertPem = "-----BEGIN USER CERTIFICATE-----dtPXNzhXXoSLmf3+AAAAAAAAAAAAAAAAAAAGDBEaICk...-----END USER CERTIFICATE-----\n";
const userSKPem = "-----BEGIN USER KEM PRIVATE KEY-----MIIJvgIBADALBglghkgBZQMEBAIEggmqMIIJpgRAP/544kgzM0T7oOqh52kmkVPN...-----END USER KEM PRIVATE KEY-----\n";
const raw_proofJSONStr = '{"duration":10,"proofNodes":[{"isLeft":true,"hash":"hRNIdH4AmKLdAhZDxmTkeyXFu5m6GUO+30PD1KAm4xM="}],"curStateSig":"-----BEGIN SIGNATURE ON MTC STATE-----...-----END SIGNATURE ON MTC STATE-----\n","userCertPem":"-----BEGIN USER CERTIFICATE-----...-----END USER CERTIFICATE-----\n","preStateHash":"tyzpoEDaZUUtCcsnbHEm+YWr+rDRxgs0tNocGEODJAI=","timestamp":160}';
// Sanitize illegal control characters in the string. 
// This is necessary because the mock 'proofJSONStr' was copied directly from a Java console output where newline characters were escaped. 
// Therefore, the literal '\n' sequence must be restored to an actual newline character for proper JSON parsing.
// Note: This sanitation step is unnecessary if the payload is transmitted via binary protocols, HTTP, or direct file transfer.
const proofJSONStr = raw_proofJSONStr.replace(/\n/g, "\\n").replace(/\r/g, "\\r");

/**
 * Executes a simulated end-to-end cryptographic workflow integrating KEM, digital certificates, and AES encryption.
 * @tutorial quick-start
 * @returns {Promise<void>}
 */
export async function test_work_flow() {
    // Generate a fresh client-side ML-KEM key pair for original enc-dec; another pair of kem keys (extractedKemPK, extractedKemSK) will be extracted for re-encryption
    const { publicKey: kemPK, privateKey: kemSK } = await pqc_funcs.kemKeyGen();

    // +++++++++Send CSR to Admin+++++++++
    // Export the KEM public key into PEM format for CSR inclusion
    const kemPKPem = await pqc_funcs.exportKemPKToPem(kemPK);
    // Construct a simulated certificate signing request (CSR) payload block
    const csr = { "user_id": 123, "kemPK": kemPKPem };

    // +++++++++Get User Cert From Server+++++++++
    // Simulate obtaining a signed user certificate string from the administrative authority
    const userCert = pqc_funcs.decodeCertFromPem(userCertPem);

    // +++++++++Check Expiration of User Cert+++++++++
    // Evaluate if the user certificate is active or has expired
    if (!pqc_funcs.isCertExpired(userCert))
        console.log("User cert is not expired");
    else
        console.log("User cert is expired");

    // +++++++++Get Admin Cert From Server+++++++++
    // Simulate obtaining the self-issued Admin root CA certificate
    const adminCert = pqc_funcs.decodeCertFromPem(adminCertPem);

    // +++++++++Check Correctness of Admin Cert+++++++++
    // 1. Evaluate if the admin root certificate is active or expired
    if (!pqc_funcs.isCertExpired(adminCert))
        console.log("Admin cert is not expired");
    else
        console.log("Admin cert is expired");

    // 2. Validate that the admin certificate possesses valid CA permissions
    pqc_funcs.isCACert(adminCert);

    // +++++++++Get Admin MLDSA PK+++++++++
    // Extract the administrative ML-DSA public key from its certificate for proof verification and user certificate validation
    const adminDsaPK = await pqc_funcs.extractAdminDsaPK(adminCert);
    console.log("Loaded Admin dsa PK", adminDsaPK);

    // +++++++++Get User MLKEM PK+++++++++
    // Extract the embedded ML-KEM public key from the user certificate for continuity encryption/re-encryption operations
    const extractKemPK = await pqc_funcs.extractUserKemPK(userCert);
    console.log("Loaded User kem PK", extractKemPK);

    // +++++++++Verify User Cert+++++++++
    // Perform signature verification on the user certificate using the admin public key
    if (await pqc_funcs.verifyUserCert(userCert, adminDsaPK)) {
        console.log("User certificate verification passed");
    } else {
        console.log("User certificate verification failed");
    }

    // +++++++++Verify Membership Proof+++++++++
    // The timestamp is specified by the user to verify the certificate's membership validity at a specific point in time.
    const time = 160;
    if(pqc_funcs.verifyMemberProof(proofJSONStr, adminDsaPK, time))
        console.log("Proof Passed!!!!!!!");
    else
        console.log("Proof Unpassed!!!!!!!");

    // +++++++++Test PQC encryption decryption+++++++++
    // +++++++++ENC MSG+++++++++
    // Prepare a plain text message payload to encrypt
    const msg = new TextEncoder().encode("Hello world");
    // Sample a 256-bit AES symmetric key for encrypting the message payload
    const aesKey = await aes_random_key_gen();
    // Encapsulate the aesKey using the original KEM public key kemPK
    const { ssCT, aesCT } = await mlkem_enc_with_aesKey(kemPK, aesKey);
    // Encrypt the target message payload using the aesKey with AES-GCM symmetric encryption
    const msgCT = await aes_enc(msg, aesKey);

    // +++++++++Re-ENC MSG+++++++++
    // Re-encapsulate the aesKey using the new KEM public key extractKemPK
    const { ssCT: reEncSSCT, aesCT: reEncAESCT } = await mlkem_re_enc_with_aesKey(kemSK, ssCT, aesCT, extractKemPK);

    // +++++++++DEC MSG+++++++++
    // Decrypt using the original KEM private key (kemSK)
    const recoveredAesKey = await mlkem_dec_with_aesKey(kemSK, ssCT, aesCT);
    for(var i = 0; i < 32; i++){
        if (aesKey.at(i) != recoveredAesKey.at(i)){
            console.error("Original KEM Decrypt Failed", i);
            break;
        }
    }

    // +++++++++DEC MSG for RE-ENC+++++++++
    // Load the KEM SK for the re-encrypted ciphertext's decryption 
    const extractedKemSK = pqc_funcs.importKemSkFromPem(userSKPem);
    console.log("Loaded User kem SK", extractedKemSK);
    // Decrypt using the extracted KEM SK for the re-encrypted ciphertext
    const recoveredAesKey2 = await mlkem_dec_with_aesKey(extractedKemSK, reEncSSCT, reEncAESCT);
    for(var i = 0; i < 32; i++){
        if (aesKey.at(i) != recoveredAesKey2.at(i)){
            console.error("Re-encrypted KEM Decrypt Failed", i);
            break;
        }
    }

    // Decrypt the transmission ciphertext bytes back into raw plaintext bytes using the recovered session key
    const decryptedMsgBytes = await aes_dec(msgCT, recoveredAesKey);

    // Decode the decrypted bytes and the original payload bytes into strings for final verification
    const decryptedText = new TextDecoder().decode(decryptedMsgBytes);
    const originalText = new TextDecoder().decode(msg);

    // Compare plaintexts to confirm successful end-to-end data transmission
    if (decryptedText === originalText) {
        console.log("Decrypt successfully:", decryptedText);
    } else {
        console.log("Decrypt failed");
    }
}

Encryption and Re-Encryption functions

Encryption with a given AES key. It firstly calls mlkem to generate a secret share and its mlkem ciphertext, then uses this secret share to encrypt the given AES key by AES-GCM.

/**
 * 
 * @param {CryptoKey} kemPK - The recipient's ML-KEM public key.
 * @param {ArrayBuffer} aesKey - The symmetric AES key to be encrypted.
 * @returns {Promise<{ssCT: ArrayBuffer, aesCT: ArrayBuffer}>} The generated shared secret ciphertext and AES key ciphertext.
 */
async function mlkem_enc_with_aesKey(kemPK, aesKey) {
    // Invoke the ML-KEM encapsulation routine to produce ciphertext and a shared key
    const { ct:ssCT, ss:ss } = await pqc_funcs.mlkem_enc(kemPK);
    // Encrypt the provided AES key using the derived shared session key
    const aesCT = await aes_enc(aesKey, ss);
    // Return the ciphertext and symmetric key mapping object
    return { ssCT, aesCT }
}

Decryption. It firstly calls mlkem to decrypt mlkem's ciphertext to recover the secret share and then uses it to decrypt the aes ciphertext to recover the AES Key.


/**
 * @param {CryptoKey} kemSK - The recipient's ML-KEM private key.
 * @param {ArrayBuffer} ssCT - The ML-KEM ciphertext.
 * @param {ArrayBuffer} aesCT - The AES ciphertext.
 * @returns {Promise<ArrayBuffer>} The decrypted AES key bytes.
 */
async function mlkem_dec_with_aesKey(kemSK, ssCT, aesCT) {
    // Invoke the ML-KEM decapsulation routine to recover the shared session key
    const recoveredSS = await pqc_funcs.mlkem_dec(ssCT, kemSK);
    // Decrypt the AES key ciphertext using the recovered shared session key
    const recoveredAESKey = await aes_dec(aesCT, recoveredSS);
    // Return the decrypted AES key bytes
    return recoveredAESKey;
}

Re-Encryption. It firstly decrypts using the original kemSK and then encrypts using the new kemPK.


/**
 * 
 * @param {CryptoKey} kemSK - The original ML-KEM private key used to decapsulate the original ciphertext.
 * @param {ArrayBuffer} ssCT - The ML-KEM ciphertext, which encapsulates the shared session key ss.
 * @param {ArrayBuffer} aesCT - The AES key's ciphertext, encrypted by ss using AES-GCM.
 * @param {CryptoKey} newKemPK - The new ML-KEM public key to re-encapsulate the recovered AES key.
 * @returns {Promise<{ssCT: ArrayBuffer, aesCT: ArrayBuffer}>}
 */
async function mlkem_re_enc_with_aesKey(kemSK, ssCT, aesCT, newKemPK) {
    // Decapsulate the original ML-KEM ciphertext to recover the encrypted AES key.
    const recoveredAESKey = await mlkem_dec_with_aesKey(kemSK, ssCT, aesCT);
    // Re-encapsulate the AES key with the new ML-KEM public key
    return await mlkem_enc_with_aesKey(newKemPK, recoveredAESKey);
}
