PQC File Sharing System

This repository contains the Java service and browser-side JavaScript library for a post-quantum file sharing system built around Merkle Tree Certificates (MTC), ML-KEM, and ML-DSA.

The Java module issues user certificates, constructs signed MTC states, and generates membership proofs. The JavaScript module verifies the certificates and proofs in the browser and provides the client-side key encapsulation and encryption workflow.

Quick start

Run the self-contained Java SQLite example:

cd java/PQC-MTC
mvn clean package
java -cp target/pqc-mtc.jar com.smu.TestSQLite

Build the browser library:

cd js
npm install
npm run build

The JavaScript build produces js/dist/pqc-lib.js and js/dist/pqc.wasm. Serve the js/ directory through a local HTTP server and open demo/index.html to run the browser demo; the WebAssembly asset cannot be loaded directly through a file:// URL.

Documentation

Browse the documentation homepage for the Java and JavaScript guides and API references. The published pages live in the independent yjm9110/smu.smc.pqc.mtc.docs repository. GitHub Pages must be enabled on that repository's main branch at its root. The stable links above always serve the latest published main and do not depend on a documentation commit recorded by this repository.

To regenerate every page from this repository's README files and source code, clone the documentation repository once, update its local main, and run:

git clone https://github.com/yjm9110/smu.smc.pqc.mtc.docs.git docs-site
git -C docs-site switch main
git -C docs-site pull --ff-only origin main
cd js && npm ci && cd ..
./scripts/generate-docs.sh

The main repository ignores docs-site/, so commits made there never change the main repository's status or require an updated repository reference.

Generate the Java API documentation from java/PQC-MTC/:

./maven_javadoc.sh

Generate the JavaScript API documentation from js/:

npm run docs

The individual commands also write into docs-site/. Generation only changes local files; it does not commit or push either repository. To publish, review, commit, and push from the independent documentation repository yourself:

git -C docs-site status
git -C docs-site add -A
git -C docs-site commit -m "Update documentation"
git -C docs-site push origin main

No documentation files or commit pointers are recorded in the main repository. No DOCS_PUSH_TOKEN or GitHub Actions publishing workflow is needed.
