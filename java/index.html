PQC File Sharing System (Java)

This directory contains the Java implementation of the Merkle Tree Certificate (MTC) service used by the PQC File Sharing System. It issues ML-KEM user certificates with an ML-DSA administrator key, builds signed Merkle tree states, and generates or validates membership proofs.

Two tree designs are included:

  • MTC_Service_Baseline rebuilds the state from the certificates valid in each time window.
  • MTC_Service_AppendOnly preserves earlier leaves and appends new certificates. This is the design used by the MySQL build runner.

SQLite implementations and examples are provided for local development. The MySQL implementation and one-shot runner are intended for deployment.

Requirements

  • JDK 8 or newer to build and run the application
  • Maven 3.x
  • JDK 18 or newer when generating the current Javadoc, because its overview uses Javadoc snippet tags
  • MySQL 8 only when using the MySQL-backed runner or example

Build

From this directory, run:

mvn clean package

The build creates the executable fat JAR at:

target/pqc-mtc.jar

The JAR's entry point is com.smu.mtc.runner.MTC_BuildRunner.

Run the local SQLite example

The SQLite workflow exercises key generation, certificate issuance, state construction, membership-proof generation, and local verification without requiring MySQL:

java -cp target/pqc-mtc.jar com.smu.TestSQLite

The convenience script builds the project first and then runs the same example:

./maven_run.sh

The example creates example.db in this directory.

Run one MySQL build round

Create a local configuration file and edit its database credentials and key paths:

cp conf/mtc.env.example conf/mtc.env
mvn clean package
java -jar target/pqc-mtc.jar

MTC_BuildRunner performs one append-only build round and exits. It loads or creates the administrator signing key, consumes a batch of pending certificates, updates the tree and state in one database transaction, and marks the consumed queue rows as processed. A failed round is rolled back so a later invocation can retry it.

Configuration values can be supplied as operating-system environment variables or through conf/mtc.env. Environment variables take precedence. The supported values are documented in conf/mtc.env.example.

The MySQL certs, nodes, and states tables must already exist. The sql/pending_certs.sql script creates the input queue table consumed by the runner. Only ADD operations are currently processed.

Generate API documentation

./maven_javadoc.sh

The generated Javadoc is written to ../../docs-site/java/apidocs/. Open the published Javadoc to browse the database integration guide, API reference, and baseline and append-only examples.
